Paste an emailed receipt

In your email app, open the receipt, choose Select All, and copy. Then tap and hold the box below and choose Paste. On a computer, click the box and press Ctrl+V.

Settings

Connect OneDrive (direct upload)

Sign in with your Microsoft account. Receipts are saved to your own OneDrive, and only you can see them.

  1. Go to App registrations and sign in with your Microsoft account. Choose New registration.
  2. Name it "Receipt Drop". Under supported account types, choose Accounts in any organizational directory and personal Microsoft accounts.
  3. Redirect URI: platform Single-page application (SPA), value:
  4. Copy the Application (client) ID into the box below and save.
Email-to-folder routine (optional)

Use this if you'd rather email receipts. The Email button sends the PDF through your phone's share sheet, with the tag below in the subject. An automation then saves attachments from those emails into OneDrive.

  1. In Power Automate, create an Automated cloud flow.
  2. Trigger: When a new email arrives (V3). Set Include Attachments = Yes, Only with Attachments = Yes, Subject Filter = your tag.
  3. Add Apply to each on Attachments, then OneDrive: Create file. Folder = your receipts folder, File name = Attachments Name, File content = Attachments Content.
